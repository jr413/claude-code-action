# データベーススキーマ設計

## 概要

TeleAI プラットフォームのエンタープライズデータモデルのデータベーススキーマ設計です。音声ファイル、文字起こし、分析結果、ユーザー管理を含む包括的なデータモデルを提供します。

## テーブル構成

### 1. users (ユーザー)
ユーザー情報を管理するマスターテーブル

### 2. sessions (セッション)
ユーザーのログインセッション情報を管理

### 3. audio_files (音声ファイル)
アップロードされた音声ファイルのメタデータを管理

### 4. transcriptions (文字起こし)
音声ファイルの文字起こし結果を保存

### 5. analyses (分析結果)
文字起こしデータの分析結果を保存

## リレーションシップ

- **users → audio_files**: 1対多の関係（1人のユーザーが複数の音声ファイルを所有）
- **audio_files → transcriptions**: 1対1の関係（1つの音声ファイルに1つの文字起こし）
- **transcriptions → analyses**: 1対多の関係（1つの文字起こしに複数の分析結果）
- **users → sessions**: 1対多の関係（1人のユーザーが複数のセッションを持つ）

## パフォーマンス最適化

### インデックス戦略
- 複合インデックス: `user_id + created_at` でユーザーごとの時系列データを高速検索
- 単一インデックス: 外部キーすべてにインデックスを作成
- 全文検索インデックス: 文字起こしテキストに対する検索性能向上

### クエリ最適化
- 大規模データセット向けのページネーション実装
- 適切なインデックスヒントの使用
- 必要に応じたマテリアライズドビューの活用

## セキュリティ考慮事項

- すべての個人情報は暗号化して保存
- アクセス制御はアプリケーション層で実装
- 監査ログテーブルによる変更履歴の追跡
